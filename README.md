# EPIGuard

Sistema web de gestão de EPI (Equipamento de Proteção Individual) industrial: controle de uso, validade e entrega de equipamentos de segurança para colaboradores de campo.

Projeto da disciplina **Engenharia de Software** — Engenharia de Computação, 3º ano, FIAP. Professor: Hercules Ramos. Desenvolvido em três entregas (Checkpoints 4, 5 e 6): idealização → protótipo → produto final.

## Problema

Empresas de infraestrutura e operação rodoviária controlam a entrega de EPI (capacete, luva, protetor auricular, colete) manualmente em planilha. Isso impede saber, em tempo real, quem está com equipamento vencido, gera risco de acidente e dificulta auditorias de conformidade (NR).

## Para quem

- **Técnico de Segurança do Trabalho** — cadastra colaboradores/EPIs, registra entregas, acompanha vencimentos.
- **Colaborador de campo** — retira e devolve EPI de forma simples, via navegador.
