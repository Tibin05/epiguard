# Identidade Visual — EPIGuard

## Nome
**EPIGuard** — une "EPI" ao papel de vigilância (guard) do sistema.

## Tagline
"Segurança rastreada, em tempo real."

## Logo (conceito)
Escudo (proteção) com um check interno (conformidade/verificação). Monocromático, funciona em selo pequeno (favicon) e em versão maior no cabeçalho do app. Construir como vetor simples no Figma — evitar gradientes ou efeitos 3D, que não reduzem bem em tamanhos pequenos.

## Paleta

| Nome | Hex | Uso |
|---|---|---|
| Grafite | `#1E2328` | Texto principal, fundo modo escuro |
| Âmbar | `#B4620D` | Acento de marca, CTAs, sinalização |
| Teal | `#1B6C70` | Links, elementos de dados/UI |
| Verde (OK) | `#2F7A4C` | Status: EPI válido — só semântico, nunca decorativo |
| Vermelho (vencido) | `#B23A30` | Status: EPI vencido — só semântico, nunca decorativo |
| Fundo | `#F1F2EE` | Fundo modo claro |

Âmbar carrega a identidade "sinalização de segurança" sem cair no laranja-EPI literal. Teal diferencia elementos de interface do acento de marca. Verde/vermelho ficam reservados só para status de EPI.

## Tipografia

- **Display** (títulos): Big Shoulders Display — condensada, remete a sinalização industrial/canteiro.
- **Texto** (parágrafos, formulários): IBM Plex Sans.
- **Dados** (datas, CA, códigos): IBM Plex Mono.
